# v0.1 体验版真机测试计划

**目标：** 在正式提交审核前，通过真机测试确认全流程可用、无白屏、无 key 泄露。

---

## 测试设备建议

| 设备 | 必测 |
|------|------|
| iPhone（微信最新版） | ✅ 必测 |
| Android（微信最新版） | ✅ 必测 |
| 微信开发者工具模拟器 | 辅助 |

---

## 测试流程 Checklist

### 1. 首次进入

- [ ] 小程序加载无白屏
- [ ] 首页正常显示「拍照识别」入口
- [ ] 无控制台报错（Error level）

### 2. 权限流程

- [ ] 首次点击拍照，弹出相机权限请求
- [ ] 选择「拒绝」后有友好提示，且按钮仍可用
- [ ] 选择「允许」后正常进入相机
- [ ] 相册选择同样测试拒绝/允许流程

### 3. 拍照识别流程

- [ ] 拍照后无转圈卡死
- [ ] 等待识别时有 loading 提示
- [ ] 识别完成后显示词卡（中英日韩）
- [ ] 例句和 kidNote 正常显示
- [ ] 多语言切换正常

### 4. 相册选择识别流程

- [ ] 相册选择正常打开
- [ ] 选择图片后正常识别
- [ ] 结果与拍照流程一致

### 5. 贴纸书功能

- [ ] 保存贴纸书按钮可用
- [ ] 保存成功有提示
- [ ] 进入贴纸书看到保存的词卡
- [ ] 贴纸书列表正常

### 6. 复习功能

- [ ] 进入复习页
- [ ] 显示已保存词卡
- [ ] 复习流程正常

### 7. 清理链路验证

- [ ] 识别完成后，云存储中对应图片已删除（或 24h 内被清理）
- [ ] 云函数日志无报错
- [ ] dryRun 定时任务正常触发

### 8. 弱网测试

- [ ] 在弱网环境下拍照识别，超时/失败有友好提示
- [ ] 不出现空白页或无法恢复的错误

### 9. AI 失败 Fallback

- [ ] 模拟 AI 服务异常时，小程序不白屏
- [ ] 有错误提示，不卡死

### 10. 安全检查

- [ ] 控制台无 `sk-`、API Key、Authorization 泄露
- [ ] 控制台无完整 base64 图片打印
- [ ] 无 cloudFileID 直接暴露在页面中

### 11. 儿童适配检查

- [ ] 页面文案适合儿童理解
- [ ] 无成人内容或不适内容
- [ ] AI 免责声明已展示
