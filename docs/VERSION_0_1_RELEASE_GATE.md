# v0.1 发布准入标准

## 可以发布的条件

### 必须全部满足

- [ ] **真实识别质量回归测试通过** — 30 张图片测试，Provider 成功率 ≥ 80%，P0 问题数 = 0
- [ ] **dryRun 定时清理观察至少 24 小时无异常** — 云函数日志返回 `ok=true`，`failedCount=0`
- [ ] **小程序备案完成** — 微信公众平台填写主体信息并通过备案
- [ ] **小程序信息和类目补齐** — 名称、图标、简介、服务类目（教育 > 语言学习）已配置
- [ ] **用户隐私保护指引完成** — 微信公众平台「用户隐私保护指引」已填写并发布
- [ ] **小程序内有 AI 识别免责声明** — 结果页面或关于页面有「AI 识别结果可能不准确，仅供学习参考」说明
- [ ] **不采集儿童姓名、学校、住址** — 代码和数据库不包含此类字段
- [ ] **不保留云存储临时图片** — 识别完成后立即删除 `recognition-inputs/`，recognition_uploads 有状态记录
- [ ] **无 API Key / cloudFileID / base64 泄露** — 控制台日志审计无敏感信息打印，storage 不保存 cloudFileID

## 不应发布的条件

满足以下任意一条，不应提交审核：

- [ ] 备案未完成
- [ ] 隐私保护指引未配置
- [ ] 仍有 P0 问题（白屏、key 泄露、图片无法删除、持续失败）
- [ ] 图片清理失败未解决
- [ ] 真实识别大面积错误（成功率 < 80%）
- [ ] 仍会输出大量角色名/品牌名（专有名词率 > 10%）
- [ ] 用户看不到 AI 结果可能错误的说明
- [ ] 云函数日志中出现 `permission denied` 或数据库权限错误
- [ ] 定时触发器未正常工作（4 次触发中有任意 1 次缺失）

## v0.1 建议定位

> **亲子语言学习实验版**
>
> 不承诺识别完全准确，建议家长陪同使用。
> 本产品基于 AI 视觉识别技术，识别结果仅供学习参考，不作为专业语言教育依据。
