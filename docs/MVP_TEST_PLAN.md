# MVP 测试计划 - 拍词贴

## 测试范围
微信开发者工具模拟器（iPhone 12 Pro Max / Android 均可）

## 测试前准备
1. 打开微信开发者工具
2. 导入 `miniprogram` 目录
3. 使用测试号或填入 AppID
4. 确认编译无报错

---
