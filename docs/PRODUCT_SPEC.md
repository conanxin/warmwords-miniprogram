# 产品规格说明书 - 拍词贴

## 1. 产品定位

### 产品名称
- **英文名**：WarmWords Mini
- **中文名**：拍词贴
- **一句话定位**：现实世界的多语言词汇贴纸书

### 核心价值
通过拍摄身边的真实物体，将观察世界与语言学习结合，在亲子、旅行、日常场景中自然习得多语言词汇。

### 目标体验
> 拍下路边的花朵 → 生成"flower / 花 / 花 / 꽃"词汇卡 → 听发音、例句 → 保存到贴纸书 → 复习记忆

## 2. 用户画像

### 主要用户
- **6-12 岁儿童**（在家长的辅助下使用）
- **语言学习初学者**（各年龄段）
- **亲子旅行场景中的家庭**
- **日常观察爱好者**

### 用户需求
- 简单有趣的词汇学习方式
- 多语言支持（中 / 英 / 日 / 韩）
- 离线可用（本地存储）
- 隐私安全（不强制上传图片）

## 3. MVP 功能

### 3.1 拍照识别
- 摄像头实时拍摄
- 相册选择图片
- 传入识别云函数

### 3.2 词汇卡片生成
- 物体识别（Mock 阶段：12 个预设词条）
- 多语言词汇（中 / 英 / 日 / 韩）
- 音标（英文）
- 例句（中 / 英文）
- 儿童友好注释
- 置信度显示

### 3.3 发音播放
- Mock 阶段：显示文字提示
- 未来：接入 TTS 云函数

### 3.4 贴纸书收藏
- 保存到本地 Storage
- 列表展示
- 清空确认

### 3.5 简单复习
- 基于 nextReviewAt 的间隔复习
- "我认识"→ 3 天后复习
- "我还不熟"→ 明天复习
- 鼓励文案（无待复习时）

## 6. 隐私与安全

### 当前阶段
- 所有数据本地存储（wx.getStorageSync）
- 不上传图片到任何服务器
- 不收集用户行为数据

### 上线前必须补充
- [ ] 隐私政策文档
- [ ] 儿童/家长知情同意机制
- [ ] 数据删除机制
- [ ] 合规审查

## 7. 技术约束

- 微信小程序要求 HTTPS
- 云函数需微信认证小程序
- API Key 必须存储在云函数环境变量
- 12MB 包体积限制（主包）
- 不支持 WebAssembly

## 8. 设计语言

### 视觉风格
- 明亮、现代、柔和、干净
- 不偏黄（避免旧纸张感）
- 圆角、大留白、轻微阴影
- 贴纸感、卡片化

### 配色
- Primary: `#667eea` (蓝紫渐变)
- Secondary: `#764ba2`
- Background: `#f5f7ff` (淡蓝灰)
- Text Primary: `#2d3748`
- Text Secondary: `#718096`

### 字体
- 系统字体（无特殊字体依赖）
- 圆体风格

### 图标
- Emoji 为主要图标来源
- 无需额外图标字体
